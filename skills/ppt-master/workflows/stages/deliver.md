# Deliver Stage

> Last step of Default and Quick Generate, after Step 7.3 / §4 export and after every post-export stage that still reads the working project (`generate-audio`, narrated or kiosk exports, visual review). It replaces the working project with one delivery folder the user can open directly. A revision of a delivered deck starts here with `unpack`.

## Delivery folder

```text
<deck title>/
  <deck title>.pptx        final deck, every installed font it uses embedded
  制作文件/                 only what a revision needs
    使用说明.md             what each item is; deleting 制作文件/ never affects the deck
    演讲稿.md               notes/total.md
    幻灯片页面/             svg_output/
    设计规范/               design_spec.md, spec_lock.md, animations.json
    图标/ 图片/ 原始资料/ 模板/ 资料分析/   only when non-empty
    .ppt-master.json        hidden restore manifest
```

`backup/`, `svg_final/`, split notes, `validation/`, `confirm_ui/`, `live_preview/`, and older exports are regenerated by the pipeline and are removed with the working project after the copy is verified.

## Pack

```bash
python3 ${SKILL_DIR}/scripts/deliver.py pack <project_path> --title "<deck title>"
```

- `--title` is the deck's own title in the user's language (the cover title, shortened only when it cannot be a file name) — never the project slug, a timestamp, or a format suffix. It names both the folder and the `.pptx`.
- The newest `exports/*.pptx` is delivered; pass `--pptx <file>` when another export is the deliverable (a `_narrated` or `_native_charts_tables` file the user chose).
- The folder is written next to `projects/` (the user's working folder); `--dest <dir>` only when the user names another place.
- Fonts are embedded by [`pptx_embed_fonts.py`](../../scripts/pptx_embed_fonts.py): each installed face is subset to the characters the deck uses (slides, layouts, masters, notes) and CFF outlines are converted to TrueType; a CJK design face the exporter parked in the latin slot also takes the East Asian slot, so the embedded face is the one Chinese text uses. Restricted-licence and bitmap-only faces are skipped, faces bundled with Office on both Windows and macOS are skipped. Read the `[EMBED]` receipt and report any face listed as `not installed` or `licence forbids embedding` — that text falls back on other computers. `--no-embed-fonts` only on the user's explicit request.
- Packing the same title again replaces the `.pptx` and `制作文件/` in place; other files the user put in the delivery folder stay.
- `--keep-workdir` only when another stage in this conversation still needs the working project.

**Success criterion**: the `[DELIVER]` receipt lists the delivery folder, the `.pptx`, the `制作文件/` contents, and the removed working project. Report the delivery folder path to the user — not an `exports/` path.

## Unpack (revision of a delivered deck)

When the user asks to change a delivered deck — they name the delivery folder, its `.pptx`, or `制作文件/` — rebuild the working project first:

```bash
python3 ${SKILL_DIR}/scripts/deliver.py unpack "<delivery folder>"
```

It recreates `projects/<original project dir>/` beside the delivery folder with `svg_output/`, specs, `notes/total.md`, `animations.json`, and assets in their pipeline places. Then follow the owning route's revision rules ([`generate-pptx.md`](../generate-pptx.md) Revision Round, [`quick-generate.md`](../profiles/quick-generate.md) §4): edit, rerun the final quality gate, notes split, `finalize_svg.py` (Default), export, and pack again with the same title.

A delivery folder without `制作文件/` (the user deleted it after sign-off) cannot be unpacked; route the deck to [`edit-native-pptx.md`](../edit-native-pptx.md) instead.
